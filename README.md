# 524のお友達メーカー

524の原画を使った、ランダムなお友達メーカー。2026-09-08の状態を初回正式版 **ver1.0（1.0.0）** として記録。

現行バージョンはpackage.jsonを正とし、画面下部にも表示する。以後の更新は[バージョン管理](VERSIONING.md)に沿って番号を進め、[更新履歴](CHANGELOG.md)に残す。

- 目は数字・記号の3文字。数字0–9と記号 + − × ÷ ＊ ★ ? ! = が使える。耳・あたまはいつもの・くま・うさぎ・アンテナ・サル・芽の6種類、口5種類、6つのカラーパレット。最初はいつもの耳を表示する。
- 文字、耳、口、パレット、体・目・口の色を固定できる。
- ひとつ前に戻す、2048×2048 PNG保存（背景色あり・透過）、X投稿画面への導線。
- 復元コードをコピー・テキスト保存・読み込み。値一式とバージョンを保存し、復元では再抽選しない。
- 固定なしの生成は毎回1/4096で524本人。通常の組み合わせから本人は出ない。

ぶち模様、虹色、グラデーション、あいことば解放、ドット絵化は今後の候補。

## 素材

public/assets/524-reference.png はユーザーの原画のコピー。原画の各色を描画時に分離し、輪郭・目のプレート・524の数字・横口を使っている。524本人と、旧コードのclassic / long / round / tiltは以前の描画のまま復元する。

public/assets/ear-atlas-v2.png は原画の手描き線に合わせた、くま・うさぎ・丸い玉付きアンテナ・サルの耳。耳は体と同じ色になり、サルの耳は横側につく。新しい耳では原画の上の突起を取り除き、元の体の輪郭を土台に耳を重ねる。新しいIDを使い、前に保存した子の耳を別の形に置き換えない。

public/assets/ear-atlas-v3.png は、根元まで同じ太さのうさ耳・棒状のアンテナ1本・双葉の芽。2×2の左上にうさ耳2本、右上にアンテナ1本、左下に芽が入り、右下は空。通常の選択と抽選は新しいうさ耳とアンテナを使用する。旧コードのrabbit / antennaは旧素材で復元する。芽も体の色に合わせて染まり、耳と同じ固定・保存・復元に対応する。

public/assets/rabbit-ears-plump-v4.png は、ユーザー提供のピンクの子を参考に描き直した、ぽってりとしたうさ耳。丸い先端・横幅・ゆるい外向きのふくらみを優先し、参考より少し長めに頭へ重ねる。通常のうさ耳はrabbit-plumpを使い、前のrabbit-straightは復元専用で保持する。画像の淡い市松は描画時に除去し、黒い筆跡だけを透過マスクとして色付けする。

public/assets/antenna-sprout-soft-v5.png は、アンテナと双葉を524の丸くゆがんだ形に合わせて描き直した素材。左に短く太い1本のアンテナ、右に丸い葉先をもつ双葉が入る。通常の選択・抽選はantenna-soft / sprout-roundを使い、以前のantenna-single / sproutは旧コードの復元用に保持する。

public/assets/glyph-mouth-atlas.png は、原画をスタイル参照としてbuilt-in imagegenで生成した数字・記号と追加の口。背景の薄い市松は絵そのものに含まれるため、描画時に黒い筆跡だけをマスクとして読み取る。外側の透明度はPNG書き出しでも維持する。

public/assets/math-glyph-atlas-v2.png は、追加の掛け算・割り算・アスタリスクの手描き文字。2×2で左上×、右上÷、左下は6本の腕のアスタリスク、右下は空。コードではアスタリスクを半角 * として保持し、全角＊も入力時に正規化する。★への自動置換は行わず、以前保存した★のコードはそのまま復元する。

public/assets/mouth-atlas-v2.png は、いつもの口の左右差や垂れた端に合わせてbuilt-in imagegenで描き直した4種類の口。2×2で左上から、にこ・ぽかん・むにゃ・ちょん。通常の選択・抽選では新しい口を使い、原画の「すん」はそのまま残す。旧コードのsmile / oval / wave / beakは旧素材で復元し、新しい口には別のIDを割り当てている。

原画と生成パーツはバージョン1の復元に使うため、更新するときも旧版を保持すること。

耳を付け替えた頭の切り抜きは、原画の左右の輪郭と接線を合わせたカーブを使う。以前の放物線との交差で生じていた角を修正し、既存コードにも同じ表示修正を適用する。原画そのものの輪郭と顔・下半身の描画は維持する。

## 動作確認

- npm run dev：開発
- npm run build：公開用の作成
- node --test tests/friends.test.mjs：抽選・固定・復元・入力検証・戻す
- npx tsc --noEmit：型の確認

WebMCPは対応ブラウザでread_friend / generate_friend / restore_friendを登録する。利用できるWebMCP検証環境がないため、実ブラウザでの契約確認は未実施。ユーザーからブラウザテストの指定はなく、ブラウザ操作によるUI確認は実施していない。生成画像はアプリと同じ描画コードを使って画像ファイルとして確認する。
