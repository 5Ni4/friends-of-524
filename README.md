# 524のお友達メーカー

524の原画を使った、ランダムなお友達の試作。

- 目は数字・記号の3文字。耳はくま・うさぎ・アンテナ・サルの4種類、口5種類、6つのカラーパレット。
- 文字、耳、口、パレット、体・目・口の色を固定できる。
- ひとつ前に戻す、2048×2048 PNG保存（背景色あり・透過）、X投稿画面への導線。
- 復元コードをコピー・テキスト保存・読み込み。値一式とバージョンを保存し、復元では再抽選しない。
- 固定なしの生成は毎回1/4096で524本人。通常の組み合わせから本人は出ない。

ぶち模様、虹色、グラデーション、あいことば解放、ドット絵化は今後の候補。

## 素材

public/assets/524-reference.png はユーザーの原画のコピー。原画の各色を描画時に分離し、輪郭・目のプレート・524の数字・横口を使っている。524本人と、旧コードのclassic / long / round / tiltは以前の描画のまま復元する。

public/assets/ear-atlas-v2.png は原画の手描き線に合わせた、くま・うさぎ・丸い玉付きアンテナ・サルの耳。耳は体と同じ色になり、サルの耳は横側につく。新しい耳では原画の上の突起を取り除き、元の体の輪郭を土台に耳を重ねる。新しいIDを使い、前に保存した子の耳を別の形に置き換えない。

public/assets/glyph-mouth-atlas.png は、原画をスタイル参照としてbuilt-in imagegenで生成した数字・記号と追加の口。背景の薄い市松は絵そのものに含まれるため、描画時に黒い筆跡だけをマスクとして読み取る。外側の透明度はPNG書き出しでも維持する。

原画と生成パーツはバージョン1の復元に使うため、更新するときも旧版を保持すること。

## 動作確認

- npm run dev：開発
- npm run build：公開用の作成
- node --test tests/friends.test.mjs：抽選・固定・復元・入力検証・戻す
- npx tsc --noEmit：型の確認

WebMCPは対応ブラウザでread_friend / generate_friend / restore_friendを登録する。利用できるWebMCP検証環境がないため、実ブラウザでの契約確認は未実施。ユーザーからブラウザテストの指定はなく、ブラウザ操作によるUI確認は実施していない。生成画像はアプリと同じ描画コードを使って画像ファイルとして確認する。
